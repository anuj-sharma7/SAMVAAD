## How honest they are

- Every number is counted from this repository, produced by a test run, or taken from a public source (ASER 2018, 2022, 2024 and UDISE+ 2024-25, 2025-26).
- Screens are screenshots of the running prototype with **fictional demo data**.
- There has been **no usability session with real mentors**, the live AI provider has **not** been run against the real API, and every pilot target is marked **"not measured yet"**.
- Speaker notes are written in Hinglish.

The same diagrams (architecture, AI request flow) are in [`docs/images/`](../images) and in the [README](../../README.md).
