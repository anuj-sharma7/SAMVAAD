# SAMVAAD data dictionary

Covers every processed file, the source registry, the SQLite tables that hold public data, and the teaching-practice knowledge base. Blocks between `<!-- BEGIN:x -->` and `<!-- END:x -->` markers are generated by `npm run data:dictionary` from the real files (column lists, the indicator table, per-source status); the prose is hand-written. Do not edit generated blocks by hand.

All of this is public, aggregate data or its provenance. None of it describes mentor visits, teachers, schools-as-individuals or classrooms, and none of it is used in any score or prioritisation.

### Column semantics (`indicators_long.csv`, schema `indicators_long/1`)

| Column | Meaning |
|---|---|
| `indicator_id` | Key into `indicator_definitions.csv`. |
| `source_id` | Key into `source_registry.csv`; the file the value was read from. |
| `geography_level` | One of `national`, `state`, `division`, `district` (see section 3). |
| `state` | Canonical UDISE+ spelling (for example "Jammu and Kashmir", "Dadra and Nagar Haveli and Daman and Diu"); empty on the national row. The 2025-26 booklet prints "&" spellings; they are mapped to the canonical name and the printed label is kept in `notes`. |
| `area` | District or division exactly as printed in the source (never silently merged or corrected); empty for national and state rows. |
| `reference_period` | Label of the survey or census year (section 4). |
| `value` | A number, or empty when the source did not publish it. |
| `ci95_half_width` | Published 95% confidence half-width (twice the standard error) where the source gives one (ASER divisional estimates), otherwise empty. |
| `value_status` | `reported`, `derived` or `suppressed` (section 3). |
| `source_locator` | Table and page the value was read from. |
| `notes` | Source markers such as "Data insufficient", the derivation formula for `derived` values, or the printed state label. |

`geographies.csv`: `geography_level`, `state`, `area_label_in_source` (the label as printed) and `first_source_id` (first source that mentioned it). It is an inventory, not a master geography list, and holds no codes.

`source_registry.csv` has one row per source attempted, whatever the outcome. `reference_year_or_period` is the period label (stored as `reference_period` in the database); `access_detail` gives the reason a source was blocked; `sha256`, `file_path` and `row_count` are filled only when a real file was downloaded and signature-checked.

## 3. Allowed values and semantics

**`geography_level`** (database CHECK constraint): `national`, `state`, `division`, `district`. `division` is the ASER (Rajasthan/other state) divisional grouping of districts. ASER district and division estimates are survey estimates, not school-level.

**`value_status`** (database CHECK constraint):
- `reported`: a number printed in the source.
- `derived`: computed by SAMVAAD from published columns; the formula is in `notes` (for example the `*_share` indicators equal schools with the facility divided by total schools, times 100, rounded to one decimal).
- `suppressed`: the source did not publish a value for this cell. `value` is empty. **Suppressed means "not published", never zero.** The importer and database enforce this both ways: a row has an empty `value` if and only if it is `suppressed`. Charts and tables must show "Not published" and must not average, sum or colour it as zero.

**`access_status`** (source registry and `public_sources`):
- `downloaded_and_validated`: a real file was downloaded and its signature (PDF header or similar), size and content checked; the only status that contributes data to the app.
- `report_downloaded`: a report file exists locally but no indicator rows are taken from it.
- `public_page_only`: a public page was reachable but exposes no downloadable table or file; it is cited, not used as data.
- `manual_download_needed`: a file exists but scripted access was refused (for example HTTP 403); a person must download it.
- `registration_or_request_required`: access needs registration or an approved request; none was submitted.
- `captcha_or_interaction_blocked`: a CAPTCHA or interaction is required; nothing was automated.
- `unavailable`: network error, HTTP error or an empty or invalid body.
- `rejected_due_to_license_or_privacy`: deliberately not used for licence or privacy reasons.

Nothing is marked successful unless a real file exists on disk and was inspected.

## 4. Reference periods

Labels are literal and never normalised across sources, because the sources measure different things:

- `UDISE+ 2024-25` (booklet, data cut-off 31 March 2025) and `UDISE+ 2025-26` (booklet, data cut-off 31 March 2026): school census counts at state/UT and national level. Both come from the same Tables 2.2 and 2.5; the two periods are separate rows under separate `source_id`s and never merged. The booklet says the data are comparable from 2022-23 onwards.
- `ASER 2024`, `ASER 2022`, `ASER 2018`: ASER Centre household survey of rural children. Divisional estimate files carry all three years; state pages and district files carry 2024.
- Values from different sources and periods are never combined into one number.

## 6. SQLite tables

Public data lives in tables that no operational (mentor) table references and that reference no visit, school or teacher.

**`public_sources`**: `source_id` (PK), `source_name`, `publisher`, `source_url`, `download_url_or_api`, `retrieved_at_utc`, `published_at`, `reference_period`, `geography_level`, `geography_coverage`, `dataset_type`, `format`, `licence_or_terms`, `access_status` (the eight values above), `access_detail`, `sha256`, `file_path`, `row_count`, `schema_version`, `transformation_notes`, `known_limitations`, `citation_or_attribution`, `is_active` (0 or 1; 1 only for validated sources), `updated_at`.

**`public_indicator_defs`**: `indicator_id` (PK), `label`, `description`, `unit`, `domain` (`school_system`, `infrastructure`, `enrolment`, `learning`), `survey_type` (`school_census`, `household_sample_survey`), `caveat`.

**`public_indicators`**: `id` (autoincrement PK), `indicator_id` (FK to defs), `source_id` (FK to sources), `geography_level`, `state`, `area`, `reference_period`, `value` (REAL, NULL when suppressed), `ci95_half_width` (NULL or greater than 0), `value_status`, `source_locator`, `notes`. Constraints: `value IS NULL` exactly when `value_status = 'suppressed'`; `UNIQUE (indicator_id, source_id, state, area, reference_period)`. Index `idx_pub_ind_lookup (indicator_id, state, geography_level)`.

**`public_ingestions`**: one row per import attempt: `id`, `started_at`, `finished_at`, `status` (`imported` or `rejected`), `rows_imported`, `sources_active`, `checks_passed`, `checks_total`, `registry_sha256`, `processed_sha256`, `detail`. A rejected import keeps the previous data active (validation failure or checksum mismatch).

When more than one period exists for an indicator (UDISE+ 2024-25 and 2025-26; ASER 2018/2022/2024), queries must filter by `reference_period`; unfiltered lookups return one row per period.

### Knowledge-base tables (teaching practice, not statistics)

**`kb_sources`**: `kb_source_id` (PK), `title`, `publisher`, `source_url`, `version_note`, `licence_note`, `language`, `file_sha256`, `retrieved_at_utc`, `extracted_at_utc`, `imported_at`.

**`kb_chunks`**: `chunk_id` (PK), `kb_source_id` (FK), `pdf_page`, `printed_page`, `text` (verbatim excerpt, 20 to 900 characters), `text_sha256`, `language`, `review_status` (`pending_review`, `approved`, `rejected`), `reviewed_by`, `reviewed_at`, `review_notes`, `created_at`, `updated_at`. A non-pending status requires a reviewer and a time. Nothing is usable for coaching until a human curator approves it.

**`practice_card_chunks`**: `card_id`, `chunk_id`, `role` (`primary` or `supporting`). Links practice cards to their supporting excerpts.

**`feedback_citation_chunks`**: `citation_id`, `chunk_id`, `pdf_page`, `printed_page`, `excerpt`. Snapshot of the exact excerpt shown with a citation so approved feedback stays traceable if the library changes.

`practice_cards.origin` (`illustrative` or `official_source`) separates the invented demo cards from source-backed drafts.

## 7. Honesty rules that govern the data

- Values are parsed from PDF text, so every table is validated by arithmetic and cross-checks (states sum to India within 0.1 percent, published ratios equal ratios of published totals, facility counts never exceed total schools, and for 2025-26 the national totals and facility percentages equal the figures the booklet prints in prose). A layout change makes validation fail instead of importing wrong numbers.
- No login, CAPTCHA, registration or licence restriction was bypassed; TLS verification is never disabled; the downloader contacts only hosts listed in `scripts/data/sources.ts`.
- Raw third-party files are kept locally and not republished; only derived statistics and short excerpts, with attribution, are stored. A public URL is not a grant of redistribution rights.
- No student or staff personal data is collected.
